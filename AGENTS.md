- no backward compatibility at all for any changes
- run npm run lint and npx tsc -b after making changes to ensure code quality
- after rust codes changes on rust/**, run cargo clippy and cargo test to ensure code quality and correctness
- no cargo fmt
- to rebuild the in-repo wasm bundles consumed by the frontend, run `npm run build:wasm` from the repo root — this invokes `wasm-pack build --release --target web` for each of `rust/fountain-wasm` and `rust/fast-qr-wasm`, writing output to each crate's `pkg/` directory. The QR reader wasm is published from `https://github.com/andrewtheguy/rxing-reader` as `@andrewtheguy/rxing-wasm` and is consumed as an npm dependency. Always invoke wasm-pack via npm/npx so it resolves to the version pinned in `package.json` devDependencies (currently `^0.15.0`) — never the system-wide `cargo install`ed binary.
